01 / Descoperă · 4 min

Când repetăm o acțiune?

Uneori nu știm de la început de câte ori trebuie să repetăm o acțiune. Știm însă când trebuie să ne oprim.

🪴

Udăm o plantă

Cât timp solul este prea uscat.

🥛

Umplem un pahar

Cât timp paharul nu este plin.

🔋

Încărcăm telefonul

Cât timp bateria nu este încărcată complet.

Gândește-te!Ce au în comun aceste situații? Găsește încă un exemplu din viața ta.
Descoperă răspunsulÎn fiecare situație, o acțiune este repetată cât timp o condiție este adevărată. Când condiția devine falsă, acțiunea se oprește.

La finalul lecției vei putea să:

  • identifici condiția de repetare și momentul opririi;
  • urmărești pas cu pas o structură repetitivă cu test inițial;
  • construiești algoritmi simpli în pseudocod și C++;
  • depistezi o buclă infinită și să propui o corectare;
  • aplici structura while într-o problemă practică.
02 / Experimentează · 5 min

Robotul și bateria descărcată

Robotul nostru trebuie încărcat până la 100%. La fiecare pas, bateria crește cu 20 de puncte procentuale, fără să depășească 100%. Alege nivelul de pornire, apoi execută fiecare pas.

Nivelul bateriei
20%
baterie < 100: ADEVĂRAT

Repetări executate: 0

Verifică mai întâi condiția, apoi încarcă bateria.
Pseudocod
baterie ← 20
cât timp baterie < 100 execută
    baterie ← min(100, baterie + 20)
sfârșit cât timp
C++ · fragment
int baterie = 20;
while (baterie < 100) {
    baterie += 20;
    if (baterie > 100) baterie = 100;
}

Codul pornește de la 20%; în simulare poți testa și alte valori. Funcția min alege valoarea mai mică dintre cele două argumente.

De ce la 100% nu se execută nicio încărcare?Condiția baterie < 100 este falsă chiar de la prima verificare. Structura while poate avea zero repetări.
03 / Înțelege · 7 min

Structura repetitivă cu test inițial

Structura while execută o instrucțiune sau un grup de instrucțiuni atât timp cât condiția este adevărată. Condiția se verifică înaintea fiecărei repetări.

Pseudocod
cât timp condiție execută
    instrucțiuni
sfârșit cât timp
C++
while (conditie) {
    instructiuni;
}
Reține!Dacă prima verificare este falsă, corpul buclei nu se execută deloc.

Trei elemente importante într-o buclă cu contor

1. Inițializarea

Stabilește valoarea de pornire: i = 1.

2. Condiția

Decide dacă repetarea continuă: i <= 5.

3. Actualizarea

Modifică valoarea: i++ înseamnă i = i + 1.

Nu toate buclele au un contor. Uneori condiția depinde de o valoare citită sau de un eveniment.

04 / Simulează · 6 min

Execută algoritmul pas cu pas

Ce afișează algoritmul de mai jos? Încearcă să anticipezi rezultatul, apoi verifică fiecare repetare.

int i = 1;
while (i <= 5) {
    cout << i << " ";
    i++;
}

Pasi înainteCondițieAfișarei după

Vezi rezultatul final și explicația

Se afișează 1 2 3 4 5. După ultima repetare, i devine 6, iar condiția 6 ≤ 5 este falsă.

05 / Exersează · 8 min

Construiește și corectează algoritmi

Numere pare de la 2 la 10

int i = 2;
while (i <= 10) {
    cout << i << " ";
    i = i + 2;
}
Rezultat2 4 6 8 10

Suma numerelor de la 1 la 5

int i = 1, s = 0;
while (i <= 5) {
    s = s + i;
    i++;
}
cout << s;
Rezultat15, deoarece 1 + 2 + 3 + 4 + 5 = 15.

A. Ordonează instrucțiunile

Folosește săgețile pentru a construi un algoritm care afișează numerele de la 1 la 10.

    IndiciuInițializarea precedă bucla; afișează valoarea curentă înainte de a o mări.

    B. Detectează greșeala

    int i = 1;
while (i <= 5) {
    cout << i;
}

    De ce acest algoritm nu se oprește?

    Bucla infinităÎn acest exemplu i rămâne egal cu 1, iar condiția rămâne adevărată. Adăugarea instrucțiunii i++; după afișare rezolvă problema.

    C. Alege o sarcină potrivită nivelului tău

    Începător

    Afișează numerele de la 10 la 1.

    Soluție
    int i = 10;
while (i >= 1) {
    cout << i << " ";
    i--;
}

    Mediu

    Afișează multiplii lui 3 de la 3 la 30.

    Soluție
    int i = 3;
while (i <= 30) {
    cout << i << " ";
    i += 3;
}

    Avansat

    Calculează suma primelor n numere naturale nenule (n ≥ 1).

    Soluție
    int n, i = 1, s = 0;
cin >> n;
while (i <= n) {
    s += i;
    i++;
}
cout << s;

    Fragmentele C++ se introduc într-un program care include <iostream> și funcția main; poți folosi using namespace std;.

    06 / Creează · 10 min

    Provocarea Design Thinking: robotul grădinar

    Cum am putea ajuta o persoană care uită să ude plantele din sala de clasă?

    1

    Empatizare

    Discută cu un coleg despre dificultățile îngrijirii plantelor. Ce nevoi are persoana care le îngrijește?

    2

    Definire

    Formulează problema: Cum am putea uda planta doar atât timp cât solul are nevoie de apă?

    3

    Generare de idei

    În perechi, propuneți cel puțin trei idei (de exemplu: alarmă, senzor, robot). Alegeți una și explicați alegerea.

    4

    Prototipare

    Construiți un algoritm: umiditatea crește cu 10 puncte procentuale la fiecare udare simulată; opriți udarea la cel puțin 70%.

    5

    Testare și îmbunătățire

    Testați valori inițiale de 20%, 70% și 80%. Schimbați algoritmul dacă rezultatele nu respectă cerința. Cereți feedback unui coleg.

    Testează prototipul

    20%
    umiditate < 70: ADEVĂRAT
    Udări efectuate: 0.
    Un posibil prototip (compară după ce ai încercat)
    int umiditate = 20;
while (umiditate < 70) {
    cout << "Udare" << endl;
    umiditate += 10;
}
cout << "Udare finalizata";

    Pentru 20% sunt necesare cinci udări; pentru 70% și 80% nu este necesară nicio udare. Acesta este un model simplificat, nu un sistem de irigare real.
